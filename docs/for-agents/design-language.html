Triage Factory

Design language

An instrument, not a machine. The housing is warm and quiet; the readout is exact. Industrial futurism enters through precision and material honesty — never through machine iconography.

00

The thesis

Two references, one idea. The Creator supplies the housing: warm, weathered, inhabited — a future built from familiar industrial parts, where the only saturated thing in frame is emitted light. Arknights: Endfield's title sequence supplies the readout: information staged in a scene, attached to what it describes, dense because it is precise.

  1. Nothing may imitate a mechanism it does not have. No vents that vent nothing, belts that carry nothing, scanlines on a screen that is not a CRT. If it looks like it does something, it must do it.
  2. Depth is light, never framing. Planes separate from the field by depth and tone. In-flow content is borderless; only things that genuinely float get a frame.
  3. Measurement is the aesthetic. The beautiful object is the dial that is exactly right — tabular numerals, a ring at precisely 34%, a 1px hairline.
  4. Warm housing, cool readout. Warm is the world, its data and its asks. Cool is the machine acting, and nothing else.
  5. Motion marks events. It is never ambience. Spend it where something happened; never on a loop that runs regardless.
01

The light model

Four layers. This is a physical rule, not a palette — it generates the palette, and it is why light mode is not dark mode inverted. In dark, attention emits. On paper you cannot emit, so attention becomes ink density: the darkest, most saturated mark on the page.

01 · Ground
Unlit field. Warm paper or warm near-black. The only layer that changes between modes.
02 · Structure
Drawn, not lit. Hairlines, rules, outlines, wireframes. Carries layout. Never competes.
03 · Measurement
One warm family. Data, gauges, contours — and the ask. Same hue at every intensity.
04 · Emission
An agent is working. The only saturated thing on screen, so it needs no label.
02

Three hues and a neutral ramp. One accent system across both grounds — a token is the same hue in light and dark, at the lightness that ground demands. The two modes are lighting conditions on the same materials, never two languages.

Rules

  1. Cool is only ever linear or point — a spine, a dot, a stroke, a beam. Warm is the only hue allowed area — fills, plates, blocks. This makes the one bad case (two saturated blocks sharing an edge) unrepresentable rather than merely discouraged.
  2. There is no success colour. Green was removed deliberately. Settled work recedes into structure; on a board where most work eventually completes, success that shouts is noise.
  3. Alarm never becomes a badge. It takes the container's edge — corner notches and a hatched foot — so it reads at any zoom and never competes with an ask for the same slot.
  4. Accents are muted by construction. #a85a3a is clay, not orange; #1f6f8b is a dulled teal. Saturated complementaries vibrate; desaturated ones are the cinema grade both references use.

  1. The ask row scales, it does not multiply. One pending thing names itself — Review pull request #761. Several collapse to a count — 2 items need you. Never two plates on one card: a card asks once, and the run page enumerates.
  2. Settled does not mean resolved. A finished run holding an open pull request keeps its ask and does not recede — the lifecycle dot goes quiet, the plate stays lit. Receding is for work that wants nothing.
  3. Attention outranks lifecycle for placement. If a card asks, the plate sits directly under the title, above the activity row, so the scan finds it before anything else on the card.
  4. Rhythm from content. Height varies because content varies — a queued card has nothing to report, a live one has its activity, a settled one collapses to its verdict. Never pad for uniformity; never decorate for variety.

On artifact indicators

There are none, and that is deliberate. Marks for each produced artifact were tried and cut: attention is the ask row's job, so the marks could only carry inventory — and inventory is a run-page question, not a triage question. Five 7px hover targets on a swipeable card is real interaction cost for information nobody is scanning the board to find. What a run produced is already said better in words by its verdict line, and enumerated properly one click away.

The activity row

Every card carries one row in the same place with the same destination — the run. Only its words change. While work is live it shimmers the agent's current command (or its last, between commands), so a board of live cards reads as a list of what is actually happening right now rather than a list of spinners. Otherwise it reads View run →. One target, one position, no state where the affordance disappears.

  1. Setup phases are activity too. Before an agent starts there is still text — fetching, cloning, starting, awaiting credentials. The row is never empty on a live card, so it never needs a spinner fallback.
  2. Present tense while running, past tense once done. "Confirming the fix across 50 runs" → "Confirmed the fix across 50 runs". The verb carries the state; the row does not need a badge.
  3. Dissolve, never truncate. One line that fades into the arrow at the right — no ellipsis. Same rule as every other overflow in this system: edges dissolve, they do not cut. A card's height must never shift because a command was long.
  4. A card is a container of targets, never a target itself. The activity row goes to the run; the assignee glyph opens its picker; an ask opens its approval. Whole-card navigation with carve-outs is the pattern that produces nested-interactive bugs — give every destination its own hit area and leave the card inert between them.
  5. A horizontal drag cancels the click. Cards are swipeable, so any pointer movement past a small threshold must abandon the press rather than navigate on release.
  6. Assignment is always visible, never hover-only. Who owns a piece of work is a scanning fact. A person is a round mark with initials, an agent a squared one, nobody a dash — distinguished by shape, never by colour. A real avatar may carry its own colours; a synthetic mark never invents any.
  7. A request never shows elapsed time; it shows an arrow. How long something has waited is not actionable and does not compare between rows, and a mixed treatment — a clock on single asks, an arrow on aggregate ones — makes two identical affordances look like different controls. One glyph, every ask.
  8. Its picker draws itself rather than appearing. The mark retires, a terminus ring takes its place, a stem grows out of it, ticks extend and labels arrive along them — then the whole thing retracts the same way. Opening is a construction, which is the blueprint-scaffold idea doing a real job instead of decorating one.
  9. Six or fewer: show everyone, no filter. A search box on a list you can read at a glance is friction pretending to be power. Below the threshold the structure is simply the whole roster.
  10. Above it, filter — never scroll. A scroll container needs a bounded height, which is a rectangle, which is the panel this treatment exists to avoid, and its clip would cut the blur field into a hard edge. So the structure never grows: five rows, always, just a different five. The empty state is not the first five alphabetically but the five actually picked — the agent, you, recent assignees, and the escape hatch.
  11. A truncation count must be shorter than the things it truncates. Right-aligned rows take their left edge from the longest string, so a verbose count becomes the widest element and reads as misaligned against the spine. +26 more, not +26 more — keep typing.
  12. No fill, no rectangle, no shadow. Separation comes from a soft-edged blur field with no border to read as a panel — the card underneath stays half-legible rather than being covered. A floating surface earns a boundary, but a boundary can be a stem; it does not have to be a box. Click a mark to try it.
  13. Recession is a property of content, never a container opacity. Dim the title, the verdict and the readouts individually. A blanket opacity composites the entire subtree, so anything floating out of a settled card — its assignee picker above all — comes out half-faded and unreadable while the thing it overlaps is not.
  14. Show the numbers whenever they exist. A settled run has a duration and a cost, and a failed one has both plus a reason to care about them — an engagement that burned four minutes and eleven cents before dying is exactly the case where the footer earns its place. Only queued cards have nothing to report.
04

Structure

The single most load-bearing rule in this system: in-flow content is borderless; only things floating above the plane get a frame.

In flow — no frame
Cards, rows, sections, panels, transcript blocks. Separation comes from a tint fill, an inset hairline, spacing, or a toned spine on the left edge. Radius 5px; nested interactive blocks step to 4px.
Floating — border 1px, radius 10px, soft shadow, optional blur.
Popovers, tooltips, dialogs, the composer. These detach from the page, so they earn chrome — and are the only place a control may look like a control.

Also standing

  1. Badges are toned text, never pills. Uppercase, tracked, in one of the three hues. A pill is chrome an in-flow element has not earned.
  2. Scroll edges dissolve, they do not cut. Mask gradients at the boundary — linear-gradient(to bottom, transparent 0, #000 8px, #000 calc(100% - 44px), transparent).
  3. Detail expands in place. It does not open on top. Prefer disclosure over dialogs; a modal is a last resort, not a default.
  4. Empty states are a line of text. No dashed drop-zones, no illustrations.

Type

Inter for human content, monospace for machine data. That split is semantic, not decorative — if a number came from the system, it is mono and tabular. Tracking scales inversely with size: the smaller the label, the wider the letterspacing.

06

Motion

Content moves on cubic-bezier(0.22, 1, 0.36, 1) at 0.34s, staggered 50ms. A sweep that traverses a field is linear at 2.2s; the bracket lap eases on [0.65, 0, 0.35, 1] over 1.4s because it is not a traversal but a fold — it unrolls from a resting L and rolls back into it, so it must arrive and depart at rest. Every animation answers "what just happened?", and at most one thing moves per card.

07

Data visualisation

Charts get the same care as type, and follow the same light model: the field is drawn in line work, and only the thing that matters is filled. Data has a native form — reach for the form the data actually has before reaching for a bar chart.

The honesty test

A contour, a cell map or a fan is legitimate when the data genuinely has that shape and the reading carries meaning. A contour needs a continuous quantity over two axes where the gradient means something. Fail the test and it is wallpaper that resembles measurement — worse than decoration, because it implies rigour it does not have. Never use topology as page texture, and never where it implies a place rather than a quantity.

Field → contours
Two axes and a magnitude: fleet pressure over executor × time, triage load over source × time, work stuck over column × age. Iso-lines in warm, weight rising with level. Line density is the reading — tight bands mean a fast climb, which separate sparklines cannot show. The ground beneath is a dotted lattice, structure not data.

Not grey blobs. The component draws its own layout in hairlines and fills as data lands. This is the structure layer doing a real job, and it makes loading legible instead of merely animated.

Chart rules

  1. Line work first, fill second. Areas get a faint tint at most; the line carries the shape. Grids are hairlines or omitted, never boxes.
  2. Emphasise the endpoint. The latest value gets a filled mark and a label; history stays unlabelled line.
  3. Tabular numerals everywhere digits align. font-variant-numeric: tabular-nums is not optional in a readout.
  4. One warm family for data. Series are separated by weight, dash and label — not by a rainbow. If a chart genuinely needs categorical colour, it needs fewer categories.
  5. Absent is not zero. A missing series stays as an outlined placeholder; dropping it silently rewrites the shape of the whole.
  6. The axis is structure. Labels are mono, 9px, tracked, in --ink-4. They never compete with the data.
08

Forbidden

Everything here was in the product and was removed on purpose. Reintroducing any of it breaks the thesis.

Machine cosplay
Scanlines, grain, vent heat, conveyor belts, bolted panels, CRT curvature. Depiction of a machine rather than being an instrument.
Decorative brackets
Corner marks that frame nothing. A bracket may mark a real boundary or a real arrival — never sit as texture.
A success colour
Green. Done recedes; it does not celebrate.
Pills for badges
Filled rounded chips in flow. Badges are toned text.
Gradient heroes
Purple-to-blue washes, glassmorphism as ornament, blur without elevation.
Topology as texture
Contours behind content, wireframe as wallpaper, maps of nothing.
09

When in doubt

  1. Ask what the element is measuring. If it measures nothing, it is chrome, and chrome is borderless, quiet and warm at most.
  2. Ask whether it is in flow or floating. That answers whether it gets a frame, and it answers it every time.
  3. Ask what state it is in, then encode with fill. Reach for hue only after fill, weight, opacity and frame are exhausted.
  4. Ask whether anything is happening. If yes and only if yes, it may emit cool.
  5. Prefer removing. Every good decision in this language so far has been a deletion.
