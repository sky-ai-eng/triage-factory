A CI check has failed on a PR you own. Find the root cause, fix it, and push the fix to the PR branch.

Read the failing run's logs before you start writing code — download whatever logs exist for the failing check and read them for the actual error, rather than guessing from the check name alone.

## Constraints

- Do not merge. Do not force push. Only push to the branch you are already on.
- If prior task memory shows this fix was already tried, try a different approach instead of repeating it.
- If the failure is infrastructure (a flaky runner, a network timeout, a quota limit) rather than a code problem, report it as unsolvable rather than writing code to work around it.
