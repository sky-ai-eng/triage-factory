# Workspace for tracker issues

A Jira or Linear issue does not name a repository. Decide which of your team's tracked repositories it belongs in from `triagefactory exec workspace list`, and add a checkout of each one the issue needs; an issue that spans several repositories gets a checkout of each, side by side under your run root.

`triagefactory exec workspace add` refuses a repository it cannot add with one of these:
- "repo is not configured in Triage Factory" — it is not in `available`. Pick from that list rather than guessing again. If the issue belongs in a repository Triage Factory does not manage, say so in your final message and stop.
- "repo is not tracked by this team" — it is configured for the organization but your team does not track it, so you can neither add nor push to it. Pick a repository from `available`.
- "repo has no clone URL on its repository row" — its profile is incomplete. Quote the error in your final message and stop; a person fixes it from the Settings page.
